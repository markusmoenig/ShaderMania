# Support

For ShaderMania support, bug reports, feedback, or questions, contact:

[nubby.leaving0w@icloud.com](mailto:nubby.leaving0w@icloud.com)

Please include the platform you are using, the ShaderMania version, and a short description of the issue. If the problem involves a shader, include the shader source or the relevant project details when possible.

You can also use the project links in the site header to visit the GitHub repository or join the Discord server.
